THE FALL / CONFIGURATION

Real-world data access

Keys are saved in Chrome local storage. They are not written into source files or GitHub.

Get your API keys

  1. Create a Cesium ion account. Copy your default token from Access Tokens. Ensure it can access Cesium World Terrain and World Imagery.
  2. In Google Cloud Console, select a project, enable billing and the Map Tiles API, create an API key, and restrict it to Map Tiles API. Google may charge for usage.
  3. Paste keys above, save, then open a new tab.

Google 3D coverage varies. If unavailable, the extension falls back to real terrain and satellite imagery. Cesium displays required map credits.
