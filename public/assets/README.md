# Required local assets

Place these files in this directory before building:
- `skydiver-freefall.glb`: a rigged humanoid with Mixamo-compatible skeleton and a freefall/skydiving animation embedded. Export your licensed Mixamo character and animation from Blender as glTF Binary. The extension intentionally has no primitive-human fallback.
- `toposcope_sunset_1k.hdr`: Poly Haven Toposcope Sunset 1K HDRI. Download the HDR file from https://polyhaven.com/a/toposcope_sunset and save it here. The gradient sky and physical lights work without this optional HDRI.

Mixamo: https://www.mixamo.com/
Poly Haven direct HDR: https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/1k/toposcope_sunset_1k.hdr

Only bundle character assets whose licence permits redistribution.
